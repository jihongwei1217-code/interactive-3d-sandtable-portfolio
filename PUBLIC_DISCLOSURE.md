# Public Disclosure

This repository is the complete public interactive edition of the embodied-intelligence modeling 2.0 project.

Only three presentation changes are applied:

- the original company/brand logo is not displayed;
- the original company/brand name is displayed as `具身智能`;
- ZIP, STL, STP, STEP, and 3MF download actions are disabled while their interface controls remain visible.

Robot model names, dimensions, scale, model-accuracy values, equipment names, scene content, and interactive workflows remain as shown in the latest project version.

The repository includes the browser implementation and public page shells. Three-dimensional preview resources are loaded as needed from the online public exhibit. Downloadable engineering packages, credentials, secrets, and non-public personal data are not included.
